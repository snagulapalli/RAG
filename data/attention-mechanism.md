# Attention Mechanism

## Overview

The attention mechanism allows a model to focus on relevant parts of the input sequence when producing each output token.

## Details

Instead of compressing the entire input into a single fixed-length vector, attention computes a weighted combination of value vectors, where weights are derived from query-key similarity.

## Related Concepts

Self-attention is used in Transformers. Multi-head attention runs several attention operations in parallel and concatenates their outputs.
